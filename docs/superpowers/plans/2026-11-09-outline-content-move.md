# 左侧目录整理执行计划

**已确认设计：** 日常在课程编排左侧目录操作；同层拖动排序，跨技能拖动直接移动至目标末尾。内容行仅增加一个“更多”菜单，选择“移动或引用到…”后用一个弹窗选择课程和技能，默认移动，可勾选保留原位置。原批量整理入口保留。不增加新后台接口、数据库表或自动发布。

**实现与边界：** 同树修改使用不可变 CourseDocument 转换，保持共享技能副本一致，以(kind,id)去重；同技能无操作，源/目标失效不移除数据。跨树复用带版本和幂等操作ID的现有接口；操作前保存当前草稿，目标加载完成后才允许提交。失败保留弹窗与重试ID，冲突要求重载；不覆盖后台最新草稿。提示引用共享范围及跨树目标先发布。个人主题沿用现有变量。
