# CTFd 实际备份适配与验收

基于已完成的 GZCTF/CTFd 导入器，对用户私有完整备份进行本地适配。源 CTFd、数据库、FRP 和题目实例均保持原样；不把私有账号、密码摘要、Flag、题目正文或附件提交到仓库。

## 已确认的差异

- ZIP 约 185.4 MiB，超过旧压缩包限制 128 MiB；包含 273 题、1320 账号、29587 提交、13132 解题引用、215 奖励和 158 个附件记录。
- 84 道 dynamic_docker 使用 Whale 插件，51 HTTP / 33 direct；需要映射镜像、端口、CPU、内存和 per-instance FLAG 环境变量。
- 150 道动态计分题、39 道标准题。动态计分保留来源元数据，训练分数取导出值，不按导入后的练习人数重算历史。
- 空表可能为零字节文件；非空损坏 JSON 仍必须报错。
- 全部密码为受支持的 Passlib bcrypt_sha256；3 个源用户名超出目标 16 字符限制，必须明确改名或跳过，不能自动覆盖已有账号。
- 一道普通题没有 Flag：保留为停用草稿，提示人工补配。

## 实施与验收步骤

1. 回归测试先证明上传上限、空表及 Whale 转换的差异。
2. 上传端点和表单使用统一 256 MiB 压缩上限；展开总量仍为 256 MiB，保留路径、条目数、符号链接及有界读取防护。
3. 实现 Whale 映射及独立 FLAG 注入模式；保持现有原生容器行为。只转题目配置，不迁入 Docker API/FRP/活动容器配置。
4. 用实际备份在隔离数据库执行预检、导入、重放；本地验收为三个超长用户名提供显式临时覆盖，不修改备份。核对账号角色/封禁、附件字节、历史数量与训练进度隔离。不会尝试猜解用户密码。
5. 运行单元/集成回归、前端检查和独立审查；记录真实样本验证结果，删除临时私有测试源码。
6. 操作指南注明反向代理上传大小和超时；导入后仍需检查草稿和镜像可用性再发布。本轮不自动打包、推送或部署。

## 验收结果

- 实际完整备份通过 HTTP 预检、执行、同包重放：273 题、1320 账号、29587 提交、215 奖励、14 类别/技能；所有题为草稿，重复执行复用批次，未创建题目实例。
- 158 个题目附件记录逐字节校验通过。备份另有站点页面/解锁等数据不转为训练内容，预检明确列出未映射表。
- 3 个超长用户名及 1 个空白用户名通过显式临时覆盖完成隔离验收。对空白用户名的覆盖/跳过新增 HTTP 回归测试；生产实际名称由管理员在预检中确定。
- 全部 1320 个密码摘要格式受支持；测试账号覆盖旧密码验证和首次登录升级，不尝试猜解真实用户密码。源管理员不升权，1 个源封禁账号保留封禁。
- Whale 76 动态 / 8 固定 Flag 语义与官方源码核对；合成端到端测试覆盖持久化、启动、重启、动态答案失效及静态多答案优先级。真实 Docker 验证 FLAG 别名只为 Whale 注入。
- 独立审查发现 >=2 GiB 的旧 Docker 内存换算使用 int 溢出；真实 Docker 复现 4 GiB 变零，修正为 long，最终检查 4294967296 字节限制通过。
- 最终常规回归：355 后端单元测试通过；228 集成测试通过、无跳过；前端检查和生产构建通过。私有整包验收单独通过，其临时源码已删除，包/密码/Flag/附件不入库。
- Spec 与代码质量审查均通过。已有第三方依赖安全公告仍存在，本轮未变更相关依赖。
- 实际 84 个源镜像未拉取或启动，镜像权限、镜像自身漏洞/启动行为需在目标题目机逐题检查。历史原始提交未记录分值的部分保持空值，不能据此声称还原逐次得分。
- 只完成本地代码和验收，未推送、发布镜像或修改在线平台。
