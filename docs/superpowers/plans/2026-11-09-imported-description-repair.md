# 导入题目补正文后仍被阻止发布

根因链路：CTFd导入为zh/en各生成一份标题正文；当前题目编辑器只更新en，merge保留其他语言；导入原正文为空时，只补en后zh仍为空，课程发布检查以Any空Body阻止。用户从课程定位进入，非全局题目库与冻结课程错位。

修复范围：维持全部既有语言正文完整的发布要求。检查返回具体缺失语言。编辑器普通保存自动补齐空白字段，并同步与编辑前内容相同的镜像字段；不同的已有翻译保留。中文已有内容且英文为空/缺失时自动显示已有正文，不用选择语言。去掉额外补齐按钮。不改Flag/镜像/积分/题目身份，与课程修复清单、版本冲突保护集成，无新迁移。

- [x] 新增前端失败用例：zh空/en补全、普通保存自动补齐、已有翻译不覆盖、真正不同的翻译不覆盖。
- [x] 新增集成失败用例：真实双语言题只保存en仍被拦截，检查能指出zh；补齐后检查与发布成功，库中原题不被覆盖。
- [x] 实现最小helper、自动保存适配、结构化缺失语言诊断和中文提示。
- [x] 浏览器复现两语言导入场景，普通保存后统一复查；测试非空翻译保留、冲突/失败不误报。
- [x] 后端单元/集成顺序执行，前端单元/类型/构建/相关浏览器回归；独立审查。暂不自动部署。

普通保存/中文回退/后续镜像同步测试先红后绿。94项前端单元、类型检查、生产构建通过。35项相关浏览器覆盖原编辑/清单/测试容器流程，其中34项原流程通过，修正中文回退边界后新自动适配场景单独复跑通过。真实双语言服务集成回归通过；此前376后端单元及317集成全量通过，当前变更无新增后端修改。独立只读语义审查通过。未打包或部署。
