# 个人学习记录与已发布技能树同步设计

## 背景与目标

`/skill-trees` 展示所有已发布且未删除的技能树。当前 `/account/learning` 仅从 `SkillTreeEnrollments` 生成记录；学员页面已移除加入入口，因此新发布的技能树无法出现在个人学习页。目标是让登录用户在个人页看到全部已发布技能树及自己的进度，同时保留已删除且曾加入的技能树历史记录。

## 页面行为

- `/skill-trees` 仍是公开发现页，展示已发布技能树及其类别、题目、课节数量，不展示个人进度。
- `/account/learning` 展示每棵已发布技能树的个人完成率、已完成类别数、解题数与课节完成数。无需先加入技能树；没有完成记录时显示 `0%`。
- 个人学习页的标题、进度标签和空状态随所选语言显示；中文界面不出现硬编码英文。
- 曾加入而后被软删除的技能树继续显示，并标记为历史记录。未加入过的已删除技能树不出现在个人页。
- “当前技能树”标记只在有效的现有加入记录上保留；不因浏览或解题而自动创建加入记录。
- 最近学习活动继续展示已完成的题目和课节，即使它们所属的技能树没有加入记录。

## 数据口径

个人记录以当前发布版本的有效类别及其中仍已发布、已启用的题目和已发布课节为范围。类别、题目、课节总数与公开技能树接口使用相同过滤规则；同一技能树内重复引用的题目或课节只计一次。完成状态继续读取用户现有的 `ChallengeProgress` 和 `LessonProgress`，共享题目的完成记录在各相关技能树中都计入完成数。空技能树完成率为 `0%`。

个人记录服务合并两组树：全部当前已发布、未删除的树，以及用户曾加入但已经删除的树。按技能树 ID 去重，并保持稳定排序。历史树按保留的最后发布版本计算其历史结构；若没有可用版本，则保留名称和历史标记，计数为零。该变更不重写进度记录、不自动加入，也不迁移现有数据库。

## 边界与验收

- 访客仍可访问公开发现页，不能读取任何用户的个人进度。
- 新发布的技能树立即出现在已登录用户的个人学习页，名称和有效内容数量与发现页一致。
- 用户解出题目或完成课节后，相关技能树的个人进度按现有记录更新。
- 下架或软删除技能树后，它从发现页消失；曾加入的用户仍能在个人页看到历史记录。
- 页面和接口加载失败时显示错误状态，不把请求失败误显示为“暂无技能树”。

## 与后续计分功能的关系

本设计只处理技能树可见范围和完成进度。题目分数、积分榜和难度分级另行设计；它们不改变本页的现有完成率定义。
