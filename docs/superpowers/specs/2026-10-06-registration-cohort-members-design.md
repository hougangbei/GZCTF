# 注册选择年级与成员可见性设计

## 背景

线上已有“后港北”用户及“24级”年级，但现有用户的 `CohortId` 均为空。技能树管理中的“成员管理”只读取选中年级已分配的账号，因此已注册但未分配的成员不可见。注册表单目前没有年级选项。

## 已确认行为

- 注册页公开读取当前启用的年级，只返回年级 ID 和名称。注册者必须选择一个启用年级；没有可选年级时显示明确提示，并暂停提交注册。
- 注册 API 校验年级仍存在且启用，并在创建用户时写入 `CohortId`。选中年级的账号立即出现在该年级的成员列表中；邮箱验证和管理员审核状态仍独立生效，未批准用户不能登录。
- 使用相同邮箱和密码重新提交待验证注册以重发邮件时，可以更新所选年级；已批准账号不能借此改年级。
- 成员管理新增“全部已注册成员”视图，支持搜索与分页，并可筛选“未分配”。每行显示用户名、真实姓名、年级、邮箱验证与审核状态；仅列出普通用户，不把管理员账号算作实验室成员。旧账号即使没有年级也能找到，由管理员手动分配，不猜测其年级。
- 当前按年级管理和手动分配能力保留。年级成员列表也标明验证与审核状态，避免把刚注册的待审核账号误认为已批准。
- 用户管理原有列表和注册审核流程继续使用；批准或拒绝不隐式改年级。管理员后续可调整成员年级。

## 接口与数据

- 新增公开只读 `GET /api/cohorts/active`，返回按名称排序的启用年级 `{ id, name }[]`。
- `RegisterModel` 增加必填 `CohortId`；服务端在创建用户或确认待验证重复提交前校验启用状态，非法或已停用年级返回 400。无启用年级时注册不可完成。
- 管理员 `GET /api/admin/cohorts/registrants` 支持 `offset`、`limit`、`search`、`unassignedOnly`，只返回 `Role.User`，包含总数和当前页；返回审核和邮箱状态但不暴露密码或凭据。已有年级成员接口补充状态字段。
- 复用现有 `AspNetUsers.CohortId` 外键，不新增数据库迁移；旧账号保持未分配。所有列表查询使用只读数据库查询。

## 验收口径

- 现有“后港北”在“全部已注册成员”和“未分配”中可见，仍未自动归入“24级”；管理员可以自行分配。
- 新注册用户选择“24级”后立即出现在该年级及全部成员列表，并根据实际状态显示待邮箱验证或待审核；未通过审核时仍不能登录。
- 伪造不存在或停用的年级 ID 不能注册；年级在打开表单后被停用时提交得到可理解的错误。
- 成员数量超过单页时可翻页，搜索不漏掉未分配用户；公开年级接口不泄露成员身份信息。
