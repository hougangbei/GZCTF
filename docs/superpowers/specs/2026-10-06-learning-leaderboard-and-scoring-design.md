# 技能树题目积分与全站排行榜设计

## 目标

为技能树题目设置固定分值；学员首次解出题目后获得对应积分。在独立的公开排行榜页面展示全站累计解题数与累计积分，并允许在同一张按时间绘制的曲线上切换指标。题目编辑器将八档英文难度收敛为四档中文选择。

## 范围与展示

- 排行榜统计当前已发布、已启用、且属于至少一棵当前已发布和未删除技能树的题目。共享题目按题目 ID 去重，每名用户首次解出只计一次；课节完成不计入榜单。
- `/leaderboard` 对访客开放，只显示用户名、名次、累计解题数和累计积分，不暴露邮箱、真实姓名、学号或解题提交内容。导航增加“排行榜”。
- 图表横轴为日期（Asia/Shanghai），纵轴可切换“累计解题数”和“累计积分”；切换后排行榜按相同指标重新排序。图表默认展示当前指标的前十名，表格展示前五十名。无解题记录时显示空状态。
- 名次按当前指标降序；同值时先比较另一指标，再按最后一次有效解题时间较早者在前，最后按用户名稳定排序。只展示至少解出一道当前有效题目的用户。
- 数据使用首次解题的 `ChallengeProgress` 时间和题目当前分值汇总。公开 API 不包含个人身份 ID；服务端短时缓存榜单，并在解题、题目分值或发布状态改变后失效。

## 固定分值

- 新题目分值默认 `100`，管理员可设置 `0` 至 `10000` 的整数；`0` 表示练习题，仍计入解题数。
- 正确 Flag 首次提交形成的 `ChallengeProgress` 计分；再次提交不重复计分。使用提示或查看题解后首次解出仍获得全分。
- 管理员更改题目分值后，所有用户的已有积分按新值重新计算，历史曲线也按当前配置重绘。题目下架、停用或脱离全部已发布技能树后不再计入当前榜单，进度记录仍保留；重新发布后重新计入。
- 数据库迁移为现有新题库题目补上默认分值 `100`。现有 `ChallengeProgress` 直接参与统计，无需逐条改写。旧比赛题目、队伍积分榜和比赛解题记录不纳入此榜。

## 难度

- 新建题目只显示四档：入门、简单、中等、困难。API 存储值分别为现有的 `Baby`、`Easy`、`Normal`、`Hard`，以避免破坏数据库中已有枚举值；默认中等。
- 旧题目若使用 `Trivial`、`Medium`、`Expert` 或 `Insane`，编辑时保留原值并显示带“旧档位”提示的中文标签，只有管理员主动更改才写入新档位。公开题目卡片和编辑器均显示中文难度，不显示英文枚举名。
- 既有难度 enum、数据和 API 输入兼容，不执行难度值迁移。英文界面显示相应英文标签。

## 验收

- 两个人解出同一共享题目时各获得一次固定分值；一人重复提交不增加积分或解题数。
- 管理员修改分值后，榜单总分和时间曲线按新值一致更新。
- 切换纵轴指标后，曲线、表头和排名同时切换；日期按北京时间展示。
- 未发布或停用题目、未发布技能树的题目不计入榜单；公开 API 不泄露用户私有字段。
- 新建题目只有四档中文选项，旧难度题目打开再保存不会被静默改值。

## 部署注意

题目分值需要加法数据库迁移。上线前按照现有更新流程备份数据库和上传文件，再部署带迁移的新镜像。积分榜首次生成时按当前题目分值计算历史解题记录，不重写原始解题时间。
