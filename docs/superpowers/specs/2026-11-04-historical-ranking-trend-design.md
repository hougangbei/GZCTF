# 历史排行榜趋势

用户已明确要求：按历史时间展示类似 CTFd/GZCTF 的累计走势，关注趋势而非当时动态计分的逐次精确值；排行榜仍仅显示一个累计总分。

使用现有 Apache ECharts 的 step:end 折线、时间轴、图例和横向 dataZoom。默认显示完整历史区间，跨年刻度显示年份，可拖动缩放查看 2024 年。积分支持扣分造成的下降和负分，解题数保持整数。

基线的总分、去重计分、通关、隐藏与封禁规则保持。图表单独读取基线原批次的冻结历史：个人正确提交按来源题目去重取最早时间，题目分值从已加密保存的原包元数据提取，奖励/扣分用原时间及原分值。不能使用管理员后来改过的当前题目分值。按日累计后接入新原生通关，末端必须与排行榜总分和通关数对齐。示意历史使用导出时分值回算，清楚说明为趋势参考。

不新增数据库结构：既有导入批次已保存冻结原题目数据，历史表保存原时间与归属。通过独立只读 ImportedScoreTimelineService 解密并投影必要数值，不向公开 API 暴露账号邮箱、密码摘要、提交 Flag 或未上榜用户记录。只请求已过滤的前十名；批量取对应批次和历史，缓存仅缓存安全的分值映射。无法解密、历史缺失或总分核对不符时保留安全的迁入日起点，不编造明细、不影响总分；响应明确是否有历史趋势。

本地只读预览也改为用原 ZIP 的正确提交时间、题目快照值和奖励逐日累计，保留 2021–2026，预览末端与源总分一致。原 ZIP、原站和线上数据库不改动。
