# 课节阅读、编辑与个人主题

用户已确认 A 方案：独立阅读页，左侧可收起的课程目录，正文与页内标题目录；不再在技能树中使用课节弹窗。题目弹窗及既有地址保留。手机通过抽屉选择课节，正文保持单列。

编辑使用 Markdown 工具栏，支持编辑/分屏/预览、图片选择/粘贴/拖入、手动保存与快捷键。预览复用安全的 Markdown 渲染。正文及标题分语言保存，并保留未编辑的语言。保存失败保留内容，本机恢复草稿按账号、课节和语言隔离，恢复/丢弃均需明确操作。迟到的保存响应不能删除新草稿。

发布仍复用已有类别选择接口。本次不增加独立服务端草稿或已发布版本快照；已发布课节的保存会改变学生可见内容，界面明确提示。浏览器返回可恢复本机草稿；站内链接离开与关闭/刷新有未保存提示。

课节库显示标题、状态、所属类别，支持搜索、状态筛选、加载失败重试和新建后直接编辑。

全平台复用现有主题机制：个人自选色优先，其次用户显式选择默认色，未覆盖时使用平台设置。课节、技能树、题目弹窗、排行榜不再以局部固定颜色覆盖个人主题。成功/错误等语义色、排名奖牌和多系列图表保留必要的分类颜色。深/浅/跟随系统保持生效。

安全与兼容：继承现有权限、发布和报名策略；Markdown 清理事件处理器和不安全链接；不变更数据库、容器配置、校园网转发或线上部署。
