# 实验室“关于”页可视化编辑开发文档

日期：2026-10-06

## 目标与已确认的范围

将现有 `/about` 改为实验室介绍页。原页面的 GZ::CTF 版本终端、项目资源链接、贡献者滚动列表和页面内版权区不再显示。站点其他位置已有的导航、全局页脚及法定署名不属于本次改版。

管理员可以自由新增、命名、排序页面板块，在板块的网格中拖放图文、图片和发展时间轴组件，并调整组件宽度。荣誉用图文和图片组件排版；第一版没有专门的荣誉卡片、成员或项目组件。内容只维护一份中文，所有访客看到同一份。公开页沿用现有赛博、终端视觉语言；移动端依据桌面内容顺序自动排成单列，不另存手机版布局。`/about` 路径和“关于”导航入口保留。

管理员在后台导航的“关于页管理”以及公开页的“编辑”按钮进入同一个编辑器。首次发布前，公开页显示“内容建设中”，不能泄露草稿。编辑器提供保存草稿、预览、发布、已发布历史和“恢复为草稿”；恢复不直接改变公开页。

同一时刻仅一位管理员账号持有编辑锁。其他管理员可查看草稿和历史，但不能修改、发布或接管。锁不会因关闭浏览器、退出登录或超时自动释放；持锁者重新登录后仍可继续编辑或手动退出。原账号不可用时，运维人员用服务器维护命令紧急解锁，命令必须记录操作者、原因、原持锁者和时间。

## 页面结构与编辑体验

页面文档使用带 `schemaVersion` 的 Puck JSON 数据，允许的层级只有“页面 → 板块 → 组件”。管理员可拖动板块和同一板块内的组件，修改板块名称，复制、删除板块或组件。板块使用 12 列 CSS 网格；组件在属性栏选择 3、4、6、8 或 12 列宽，最小宽度和碰撞由编辑器约束，组件之间不重叠。窄屏按文档顺序单列显示，图片自适应容器，时间轴纵向排布。预览提供桌面和手机屏宽，公开渲染与预览复用同一套组件。

第一版组件：

| 组件 | 可编辑字段与行为 |
| --- | --- |
| 图文 | 标题和正文；正文提供可视化编辑及 HTML 源码切换，包含标题层级、段落、粗斜体、列表、引用、链接、预设文字颜色和对齐、表格。表格用富文本编辑器扩展实现；源码仅限允许的内容标签和属性。 |
| 图片 | 平台上传或 HTTPS/HTTP 外部链接、替代文字、可选说明和跳转链接；上传后使用本站资源 URL。 |
| 发展时间轴 | 多条事件，可增删及手动排序。每条包括自由填写的时间标签、标题、图文说明和可选图片。时间标签不被解析成日期，也不触发自动排序。 |

页面标题供浏览器标题和编辑器识别，默认“关于实验室”，管理员可改；导航仍叫“关于”。没有已发布版本时只渲染建设中状态。发布后的公开页不显示编辑框、拖动手柄或草稿状态；管理员额外看到“编辑”入口。

## 内容与安全边界

Puck 配置只注册上述板块和组件。服务端接收 JSON 时再次按显式组件类型、字段、宽度枚举和层级进行校验，不信任客户端传来的 React 组件名或任意属性。为防止过大页面，首版限制 30 个板块、总计 200 个组件、单个时间轴 100 条事件、完整文档 2 MiB；超限返回明确校验错误。版本内容保存为结构化 JSON，不保存可执行页面代码。

图文的“HTML 源码”只编辑该图文组件正文，不能输入整页 HTML、`<script>`、`<style>`、事件处理属性、iframe、自定义 CSS 或 JavaScript。服务端在保存草稿时使用 HTML 解析型清理器的收紧白名单处理正文和时间轴说明，拒绝危险 URL scheme；预览及公开页渲染前也使用浏览器侧 HTML 清理。可以采用 [HtmlSanitizer](https://github.com/mganss/HtmlSanitizer) 和 [DOMPurify](https://github.com/cure53/DOMPurify)。白名单覆盖段落、标题、强调、列表、引用、链接和表格等内容标签，以及 `href`、`title` 等必要属性；颜色和对齐使用预定义样式类，不接受任意类名或内联样式。两端禁止 `style` 标签及属性。编辑器要告知管理员被清理的内容；保存后的规范化 HTML 成为下一次编辑的来源。普通链接仅允许 `http:`/`https:`；外部图片地址要求 `https:`，本站图片使用 `/assets/` 地址。外部图片可因第三方失效，页面显示替代文字。

平台图片走专用管理员上传入口，限制单图 10 MiB，复用现有 `IBlobRepository.CreateOrUpdateImage` 将有效的光栅图片存为 WebP 或 GIF，避免把任意上传文件或 SVG 作为页面图片直接嵌入；按实际图像内容校验，不只依赖文件扩展名。已被草稿或任一发布版本引用的本站图片不得通过现有资源删除接口物理删除，保证历史版本可恢复。外部图片不作本站备份。

公开接口只返回当前已发布文档；草稿、锁信息、历史和上传入口均要求现有 `Role.Admin`。所有写操作还要在服务端验证当前持锁账号，不能仅靠前端隐藏按钮。沿用现有管理员操作日志，为获取/释放锁、保存草稿、发布、恢复版本和紧急解锁定义稳定动作代码；日志记录目标版本、操作者和结果，不写入整页 HTML。

## 状态、数据与接口

建议新增独立 `Features/AboutPage` 模块和两张表：

1. `AboutPageState`：固定主键的单行状态，保存草稿 JSON、草稿修订号、当前发布版本 ID、持锁账号 ID/当时名称、锁创建时间和草稿更新时间。持锁账号 ID 保留为快照，不设置会因删除账号而自动清空的外键。
2. `AboutPageVersion`：不可变发布快照，包含版本序号、文档 JSON、发布账号 ID/当时名称、UTC 发布时间、来源草稿修订号。所有已发布版本保留，不自动清理。恢复旧版本只复制其内容到草稿；再次发布产生新的序号。读取历史文档时按 `schemaVersion` 执行显式迁移；遇到未知版本只读报错，不尝试渲染未知组件。

服务端 API 约定：

| 方法和路径 | 行为 |
| --- | --- |
| `GET /api/about` | 匿名可读；返回已发布版本及文档，未发布时返回 `published: false`。使用发布版本 ETag，发布后立即使旧缓存失效。 |
| `GET /api/admin/about` | 管理员读取草稿、修订号、锁状态和当前发布版本；非持锁管理员只读。 |
| `POST /api/admin/about/lock`、`DELETE /api/admin/about/lock` | 获取锁、同一账号重新进入或由持锁者手动释放。其他账号获取已占用锁时返回 `409`。 |
| `PUT /api/admin/about/draft` | 持锁者提交文档和预期修订号；校验、清理并保存，修订号不符返回 `409`。 |
| `POST /api/admin/about/publish` | 持锁者按预期修订号原子创建版本并切换公开指针；空文档不能发布。 |
| `GET /api/admin/about/versions`、`GET /api/admin/about/versions/{id}` | 管理员分页查看历史及单个快照。 |
| `POST /api/admin/about/versions/{id}/restore` | 持锁者将历史内容复制为新草稿，原公开版本继续生效。 |
| `POST /api/admin/about/images` | 管理员上传并转换页面图片，返回本站图片 URL。 |

预览是管理员前端路由，读取草稿并使用与公开页相同的渲染组件，不需要公开预览 API。获取锁、保存、发布、恢复和释放锁必须在数据库事务内检查状态；同一账号多标签页也通过草稿修订号避免覆盖。网络失败保持编辑器本地未保存内容，明确提示重试；发布失败不得改变当前公开版本。所有时间统一存 UTC。

紧急解锁仅是服务器命令，例如 `dotnet GZCTF.dll about unlock --operator <运维标识> --reason <原因>`；它读取数据库配置，不开放 HTTP 路由。执行前展示当前锁信息，写系统/操作日志后在事务内清锁，并保留草稿。没有锁时返回幂等结果。实现时不把口令或连接串输出到日志。

## 开发顺序与验收

1. **依赖验证与组件模型**：在隔离页面验证 Puck 组件、网格拖放、宽度字段、手机预览、HTML 源码切换与仓库现有构建；定义带版本号的文档 schema 和迁移策略。
2. **持久化与工作流**：增量迁移、匿名发布读取、管理员草稿和锁、发布事务、历史及恢复、紧急解锁。为权限、锁冲突、修订冲突、版本不可变和首次空状态写集成测试。
3. **编辑器与公开页**：图文、图片、时间轴，后台与公开页双入口，建设中状态，桌面网格与手机单列；浏览器验证拖放、宽度、预览、发布后展示和恢复。
4. **内容安全与资源**：服务端组件白名单和 HTML 清理、客户端预览清理、图像上传及在用资源保护。验证脚本、事件属性、危险链接和 SVG 无法在管理员预览或公开页执行。
5. **交付检查**：运行项目现有前端类型检查、相关单元/集成测试和聚焦浏览器场景；检查桌面及窄屏、中文内容、暗色/亮色主题、键盘可访问性、审计记录与无关文件改动。

验收场景：访客初始看到“内容建设中”；一位管理员编辑草稿时另一位只读且不能接管；持锁者手动退出后第二位可编辑；原账号失效时运维命令可记录并解锁；未发布修改不出现在公开页；发布后立即展示；旧版本可恢复为草稿并再次发布；图文、图片和时间轴在桌面与手机可读；不受信任 HTML 不执行；原“关于”页的平台资源、版本和贡献者内容不再出现。
