# CTFd 成绩接续设计

用户已选择：保留 CTFd 导出时总分作为训练平台起点，之后新题继续累计；旧题通关同步，重做不重复加分。原 CTFd 保持原样。

## 一次性计分迁移

新增显式导入选项 `MergeScores`，默认关闭，界面说明必须同时迁入账号和历史，仅支持 CTFd 个人模式。导入预检和指纹绑定该选项。管理员启用后，按备份中每题当前 value 乘个人唯一正确解题记录，合并个人奖励/扣分建立固定基线，不拿空缺的逐次提交分值猜历史。历史仍独立保留。

每个来源只允许建立一次基线：同一备份和同一跳过账号集合可重试，不重复写入；变更备份或跳过集合不能追加/重算已冻结基线，必须使用非成绩迁移模式导入后续内容。不能把多人队伍成绩分配给个人。冻结榜、来源引用缺损或超过积分范围的包必须在预检阻断，不能假装恢复公开榜。

## 通关与排行榜

保存每个映射账号的来源、固定总分、旧通关数、是否隐藏、原最后得分时间、迁入时间和批次。未产生旧成绩的账号不因迁入而出现在榜单。隐藏账号不公开上榜，封禁账号同样排除。来源管理员只按既有账号导入规则降为普通用户。

唯一正确解题记录写入 `ChallengeProgress`，保留最早成功提交时间并关联成绩基线。原有唯一约束阻止同题重复通关；这些已包含在旧基线的进度不再作为新积分计算。没有映射或明确跳过的来源账号只保留历史，不认领现有同名账号。若已有未归账的本地通关与本次基线冲突，预检阻断，避免静默覆盖正式成绩。

排行榜 = 固定旧总分 + 基线后原生有效题目的首次通关分。旧基线不依赖题目当前是否发布/启用、镜像是否存在或后来调整分值。通关数为旧通关数加新增通关数。合并题目时保留已归账标记，防止合并后重复计分。同分按平台既有规则排序，不承诺与源 CTFd 的同分顺序完全相同。

图表将旧成绩以迁入日的一笔起点呈现，后续新成绩按实际时间累计，不伪造当年的逐日得分曲线。排行榜只显示统一累计积分，不展示旧分/新增拆分；迁入来源仍在后台留档。来源账号隐藏状态对后续该账号的训练排行继续生效。

## 一致性与安全

基线、通关、批次、账号和历史在同一个导入事务内提交。来源锁和账号锁覆盖预检及写入，唯一索引防并发重试。基线写入后清理排行榜缓存；不运行容器、不改源站。每日通关投影只按真实旧解题日期重建，不把旧解题当作今天的新活动推送。

该功能需新增迁移；默认关闭保持现有导入行为。已按旧版本只迁历史的来源可用相同原始备份启用成绩迁移，前提是没有冲突的本地通关。版本恢复必须使用匹配数据库备份，不能仅切回旧镜像。

## 验证

合成测试覆盖动态题导出值、扣分/负分、隐藏/封禁、原时间、跳过账号、重试/并发、换包/跳过集合变化、未发布与停用、调整旧分值、原生新题加分、同题重复答题、合并题目、失败回滚和原模式不变。实际私有备份核对 13132 个唯一旧通关、215 条扣分总计 -17960；完整导入逐个账号总分与独立算法对照，并检查公开榜成员与总分，不提交私有数据。
