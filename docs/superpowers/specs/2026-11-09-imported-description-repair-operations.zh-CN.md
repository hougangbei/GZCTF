# 导入题目补了描述仍无法发布

根因：CTFd适配会为每道题同时创建zh、en语言版本。旧编辑器只更新en；原正文为空的题目即使补了可见说明，zh仍为空，发布检查要求每个现有语言版本正文完整，因此继续阻止。问题并非操作者没有填写，也不应删除重建或重复导入。

修复后，发布检查以challenge_body_missing返回确切空正文语言locales（如zh），界面显示中文解释。编辑器明确显示其他不完整语言及当前编辑的en版本。

处理方式：从课程“逐题修复/定位问题”打开题目，确认当前题目说明已完整，点击“保存并补齐空白语言”。该操作只将当前标题/正文复制到其他已有语言的空白字段；不新增语言，不翻译文本，不覆盖已存在的非空标题或正文。普通“保存草稿”不自动补齐，以免无提示改变其他语言。

保存成功后清单标记待复查；可连续处理多题，最后统一复查。补齐保存失败或版本冲突不会显示已修复。原Flag、镜像、附件、题目ID和分数保持既有保存语义；课程草稿更新不会覆盖题目库或其他课程的冻结版本。

本次不新增数据库迁移，也不自动修改已导入的正式数据。当前修复尚未打包或部署到校园平台，需使用包含此修复的新版本才能看到补齐按钮。
