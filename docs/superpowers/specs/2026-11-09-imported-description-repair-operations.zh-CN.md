# 导入题目中英文自动适配

根因：CTFd适配会为每道题同时创建zh、en副本。旧编辑器只更新en；原正文为空的题目即使补了可见说明，zh仍为空，发布检查因此继续阻止。

修复后无需选择语言或额外点击补齐按钮：题目描述填写一次，普通保存即可自动适配现有语言版本。

保存规则：空白标题/正文用当前填写内容补齐；与编辑前可见内容完全相同的字段视为镜像副本，后续编辑一起同步；不同的已有翻译保留。不会对不同语言做机器翻译。只有中文、或英文为空而中文已有正文的题目，编辑器自动显示现有正文，保存后同步原中文及兼容版本。

发布检查仍要求每个既有版本正文完整，并明确列出缺失语言。保存后仍需统一复查才能发布。数据保存失败/冲突不会误标已修改。Flag、镜像、附件、积分和题目身份沿用原保存逻辑。

不新增数据库迁移，不自动批量修改正式数据。本修复尚未打包部署，需更新包含修复的版本后普通保存才能使用自动适配。
