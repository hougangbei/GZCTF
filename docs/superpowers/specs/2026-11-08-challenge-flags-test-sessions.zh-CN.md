# 题目弹窗、动态 Flag 与测试实例

## 题目界面

按用户确认的方案改成纵向结构：正文、紧凑的实例操作栏、Flag 提交栏、折叠的帮助/官方题解/社区 WP。桌面提交框与按钮同一行，小屏堆叠；保留剩余时间、复制、Web 打开入口、延长、停止与附件下载。颜色沿用个人主题与强调色，关闭学员题目弹窗不会停止学员实例。

## Flag 统一格式

新建和导入动态容器统一使用 GZCTF 模板引擎，推荐 `nynuctf{[GUID]}` 或 `flag{[GUID]}`；`[GUID]` 在每次启动时替换为随机 GUID，不能将占位符原样注入容器。原有 GZCTF `[TEAM_HASH]`、`[LEET]` 等模板语义保留。CTFd Whale 的随机 Flag 可以使用同样的自定义模板前缀，空模板使用 `flag{[GUID]}`。

按用户要求，不再支持动态模板的 `{userId}`：编辑页明确提示，发布或新启动也拒绝此写法。原来使用该写法的题目需要管理员改成 `[GUID]` 后保存，并在课程里统一发布。不会批量重写已有静态 Flag；静态题的原值、多个有效值及大小写校验规则保留。已运行学员实例仍按启动快照与原分配 Flag 判题，不强制重启。

保存导入题目不再丢失 `FlagMode`、来源标识、附件及正文资源元数据。CTFd Whale 保持 `FLAG` 与 `GZCTF_FLAG` 环境变量兼容；本地/GZCTF 不无条件增加 Whale 别名。已被旧编辑器保存而丢失模式的 CTFd 容器，可按不可变来源类型恢复 Whale 语义。原本不存在的正文或附件不自动伪造。

## 管理员测试实例

新版配置页启动测试时创建页面会话 UUID，服务端绑定管理员、题目、会话和确切实例 ID。页面每20秒续租，服务端租约90秒，同时更新实例与容器截止时间。

- 正常离开配置页、切换账号/课程/题目或触发 pagehide，发送带 keepalive 的专用停止请求。
- 取消未保存离开提示时页面未离开，实例继续运行。
- 在保存/启动请求完成前离开，后续不能再启动；若启动已在服务端完成，客户端释放确切旧会话实例，短租约作为兜底。
- 浏览器历史缓存恢复会换会话标识，旧停止请求和旧保存回调无法操作恢复后的新测试。
- 关机、浏览器强退、断网或后台节流可能导致停止请求无法送达。租约不再续期后90秒失效，现有每3分钟清理任务回收容器；在服务与题目机正常时理论上最长约4.5分钟。远端 Docker 不可用时清理可延后，不能承诺关页瞬时物理删除。
- 不接管或停止同账号的正常学员实例、其他页面的测试实例或后续替代实例。旧页面留下的无会话测试可在实例管理中显式停止。

管理员测试只验配置，不记学员通关或积分。原 CTFd、题目镜像、Harbor、校园入口均不修改。
