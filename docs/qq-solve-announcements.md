# QQ 解题播报

管理员可以在「系统设置 → QQ 解题播报」中连接 NapCat 的 OneBot 11 HTTP 服务。该功能默认关闭；不需要 Ollama。

1. 在 NapCat 中登录要发言的 QQ 号，并启用 OneBot 11 HTTP 服务，确认该账号已加入目标群。
2. 在 GZCTF 填写 NapCat HTTP 地址、访问令牌（如果 NapCat 启用了鉴权）和群号。GZCTF 运行在 Docker 中时，地址必须从 **GZCTF 容器内部**可访问；NapCat 在宿主机上时可尝试 `http://host.docker.internal:<端口>`，在同一 Docker 网络中时使用服务名。
3. 编辑消息模板，选择技能树和比赛解题来源，开启播报并保存。
4. 点击「发送测试消息」。只有目标群实际收到消息，才说明地址、鉴权、群号与机器人发言权限都已配置正确。

模板支持 `{member}`（解题成员）、`{challenge}`（题目）、`{source}`（技能树或比赛）、`{team}`（年级或比赛队伍）、`{time}`（发送时的本地时间）。例如：`🎉 {member} 解出了 {challenge}（{source} / {team}）`。

技能树题目只在成员首次解出时播报；原有比赛题目在比赛判题确认答案被接受时播报。发送失败会记录服务端警告，不会把正确提交改成失败。NapCat 不可用期间的消息不会自动补发。管理员 API 不返回已保存的访问令牌；填写新令牌可替换旧值，勾选「清除已保存的令牌」可删除它。
