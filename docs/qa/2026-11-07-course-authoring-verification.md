# 课程编排与统一发布验证记录

本轮基线：`183e2c5b`，实施分支 `codex/course-authoring-workspace`。

## 已实现

- 四层目录在一个工作区创建、从库添加、排序、移出与编辑，完整课节/题目编辑携带课程上下文返回。
- 工作区元数据、封面、结构和正文版本独立保存；统一发布切换不可变快照。
- 同一内容跨路径维持稳定身份、一份通关进度与积分；不同课程正文按课程版本读取，运行/Flag/计分冲突阻止发布。
- 发布检查包括依赖、必需附件、共享影响、目录变化、题目分值与镜像/端口。预览使用当前已保存工作区的准备结果。
- 工作区与内容并发令牌、差异核对、新建幂等恢复、离开提醒、账号/课程草稿隔离。
- 私有草稿封面、图片和附件；发布快照引用授权；七天宽限的无引用私有上传回收，保存/发布与清理使用同一引用锁。
- 运行中实例保持启动配置和 Flag；未启动会话使用新发布配置；管理员测试实例不授分。
- 老公开数据迁移为初始快照，旧链接/导入/计分保持兼容，显式旧树管理入口不能覆盖新工作区。

已验证关键案例包括：

1. 空白树内连续新建类别、技能、课节；编辑正文并返回原位置；统一发布后学员读取正确标题与正文；再保存草稿时公开版本保持不变。
2. 同技能在多个类别复用维持本草稿定义；同题跨课程只计一次；A/B 课程正文分别读取各自快照。
3. 丢失创建响应、关联保存失败、关闭重开对话框均复用同一创建标识；明确校验失败允许修正。
4. 并发保存 409 保留本地输入并显示完整差异；无效或部分课程上下文不会降级成全局内容写入。
5. 工作区软删/合并资源在发布时再次验证，不重新公开已失效身份；共享运行配置语义比较，不因 JSON 空白误判。
6. 私有上传匿名不可读、发布后正文引用可读、缺失引用文件阻止发布并保留旧版、已发布/运行引用受删除保护。
7. 已启动实例发布后保持旧 Flag 和镜像，新的实例使用新配置，未启动错 Flag 会话不会永久绑定旧 Flag。
8. 桌面/手机、浅色/深色/个人主题、目录排序与键盘、旧链接、导入成绩与排行榜、WP 上传和课节图片全部回归。

本轮共 **917 个独立测试用例通过**：356 后端单元 + 279 集成 + 49 前端单元 + 190 浏览器 + 43 工具；重复定点验证不重复计数。

## 已知边界

- 本轮验证本地 Docker 部署模式；没有执行 K3s + MinIO 云模式、校园网络负载或生产部署验收。
- 静态检查为 0 条错误、55 条现存警告；新编排模块的定点静态检查无新增警告。仍有 NuGet 依赖安全告警。测试通过不等于零 bug 或无安全风险。
- 镜像配置可解析不等于远端题目机已经成功拉取/启动；工作区保留管理员测试容器功能。
- 历史已公开上传不自动变私有；新草稿使用新私有存储路径。只存在浏览器本地且七天未保存引用的附件可能被回收，届时需重新上传。
- 数据库迁移不能仅用旧镜像回退；需恢复匹配数据库、文件与配置备份。
- 本轮尚未推送、构建离线镜像包或部署到正式平台。
